# PowerBI-Sales-Dashboard

## Overview 
This project is an interactive sales dashboard built using Microsoft Power BI. It helps visualize sales performance through charts, KPIs, and other visual reports to support business decision-making.

## Tools Used
- MIcrosoft Power BI
- Microsoft Excel
- Jupyter Notebook
- Python (Pandas, Numpy)

## Features 
- Interactive dashboard
- Sales trend analysis
- KPI cards
- Charts and graphs
- Filters and slicers

## Future Improvements

- Add more interactive report pages.
- Connect to a live database.
- Automate data refresh.
- Publish the dashboard to the Power BI Service.
